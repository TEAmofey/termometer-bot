# Инструкции для агентов

## Синхронизация и развёртывание

- Изменения кода доставлять на сервер **только через Git**: локальные изменения → проверка → коммит → push → получение нужного коммита на сервере.
- Не синхронизировать код через `scp`, `rsync`, архивы, `tee` или прямое редактирование файлов на сервере. Исправления сначала делать в локальном репозитории и проводить через Git.
- Репозиторий: `https://github.com/TEAmofey/termometer-bot.git`.
- SSH: `ssh -l mofeytea 130.193.55.169`.
- Каталог приложения: `/home/mofeytea/termometer-bot`.
- Менеджер процессов: PM2; имя процесса: `thermometer`; `PM2_HOME=/home/mofeytea/.pm2`.
- Подробный порядок действий и особенности доступа: [docs/deployment.md](docs/deployment.md).

Перед обновлением проверять Git-статус локально и на сервере. Не затирать незакоммиченные изменения и не выполнять `reset --hard` или `clean` для устранения расхождений. На сервере могут оставаться изменения от прежнего копирования файлов: сначала сравнить их с локальными и сохранить нужные изменения в Git.

Секреты, `config.py`, логи и резервные копии БД не коммитить. Миграции БД хранить в Git и выполнять на сервере из доставленной версии после проверки и создания резервной копии. SSH использовать для Git-операций, запуска миграций, управления процессом и диагностики.
